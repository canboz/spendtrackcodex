# Expense Logic Review

## Goal

Review the correctness and reliability
of expense-related JavaScript logic.

## Instructions

1. Read README.md and app.js.
2. Identify how expense values are represented.
3. Review monthly total calculations.
4. Review yearly total calculations.
5. Review input validation.
6. Check decimal and boundary cases.
7. Check localStorage interactions.
8. Identify confirmed issues and potential risks.

## Output Format

Provide:

- Summary
- Verified findings
- Potential risks
- Recommended improvements
- Suggested test cases

## Rules

- Do not modify files.
- Do not change the data format.
- Do not introduce dependencies.
- Reference relevant code.
- Do not report hypothetical issues
  as confirmed bugs.
