# UI Review

## Instructions

1. Read index.html and styles.css.
2. Identify the main UI sections.
3. Review responsive CSS rules.
4. Review accessibility attributes.
5. Check keyboard navigation.
6. Check horizontal overflow.
7. Identify potential visual issues.

If Playwright MCP is available:

- Open the running application.
- Test at 390px, 768px, and 1440px.
- Capture screenshots.
- Inspect browser console errors.

## Output

Provide:

- Verified UI issues
- Potential risks
- Screenshot references, if available
- Recommended fixes
- Priority levels

## Rules

- Do not modify files.
- Do not claim browser testing was performed
  unless it actually ran.
- Preserve the current visual identity.
